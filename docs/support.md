# Horizon Support

Horizon lets you browse files, read documents, and review changes on computers you pair with from your iPhone or iPad.

## Contact

Email Michael Pace at [growth@signalrankmedia.com](mailto:growth@signalrankmedia.com) for help, or [open a support issue](https://github.com/mikepace-projects/Horizon-Host/issues/new) to report a non-sensitive problem. Include your Horizon version, iOS or iPadOS version, device model, and steps to reproduce the problem. Issues are public. Do not include pairing codes, passwords, API keys, private network addresses, or confidential files. Send sensitive requests by email instead of posting them in an issue.

## Connecting a computer

1. Install Horizon on your computer using the [public downloads](https://github.com/mikepace-projects/Horizon-Host/releases).
2. Set up Tailscale on your computer and mobile device and sign them into a network authorized to connect them.
3. Run the Horizon app or a Remote Host on the computer. Use its Connect Device action to show a pairing code.
4. On your iPhone or iPad, choose Scan QR Code or Paste Code and approve the connection and folder access.
5. Open a Project. A fresh iPhone client needs Projects saved from another Horizon client sharing that Host; the iPad client can also manage Projects.

If a computer is offline, check that its Horizon app or Remote Host is running and that Tailscale can reach it. If a pairing code has expired, generate a new one on the computer. If the camera is unavailable, use Paste Code.
