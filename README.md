# Horizon Host

Horizon Host makes project folders on another computer available to Horizon.

## Install

In the Horizon desktop app, open **Settings > Hosts > Add host**. Choose the remote operating system, then follow the installation and pairing instructions. No GitHub account is required to download the installers.

Supported release targets:

- Linux x64 with systemd
- Windows x64
- macOS on Apple silicon

Install Tailscale on both computers and Git on the remote host for source control. Run the installer from a normal terminal, without administrator/root privileges.

## Downloads

Each release includes a host binary and a SHA-256 checksum for each platform. Use the release selected by the desktop app to keep host protocols compatible.

This repository distributes compiled installers, checksums, and public privacy/support documentation. Application source is maintained separately.
